## 适配器及写入边界

07dfb24c9334c5011ac84e326ac9c3529a8f7085，共 298 个登记适配项、288 份去重脚本。
来源、维护者、许可证及脚本均在 assets/shiguang/warehouse.zip；原文件按 SHA-256 校验。
从框架提供的模块 APK 路径读取资源，不读取日历 APK 的同名 assets。

使用单次页面的 WebMessagePort 对接拾光 Promise 协议，不暴露 Java 对象。

saveImportedCourses 只暂存结果，任务结束后校验并打开统一预览；
替换、追加、新建仍调用已有串行事务及撤回链路。关闭预览不写入。

导入保留目标课表的学期、节次和提醒配置；脚本返回作息或学期时在预览明确提示。
不导入学分、组合作息及课表元数据。自定义时间必须精确匹配目标节次，
星期、节次、周次或必填字段不合法时整批拒绝，并报告课程位置。
导入预览冻结目标课表，最终由现有事务入口再次校验配置。
