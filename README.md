# ColorOS 日历增强 · CourseAlarm


一个 LSPosed 模块（modern libxposed API 102），注入 ColorOS 日历的课表页

---

## 功能

### 一、课程表就在主页

底栏「日历 | 待办 | 课程表」三段式

「导入课表 / 导出课表 / 课表主题」都在底栏右侧，原来右上角那个菜单已收进底栏。

### 一·补充（v0.6.0）：底栏左右钮按页独立

| 页面 | 左圆钮 | 右圆钮 |
|---|---|---|
| 日历 / 待办 | 视图菜单（宿主原样） | 新建（宿主原样） |
| **课程表** | 周次选择 | 课表 ⋮（创建课表 / 课表管理 / 分享课表 / 课程提醒 / 创建桌面快捷方式 / 导入 / 导出 / 课表主题 / 回到本周 / 刷新） |

课表页把主页顶栏收起（高度动画），自己画一行「课程表」标题；切页是「标题淡入淡出 + 课表 0.96↔1 缩放」的缓动，
和宿主切「待办」同一个观感。在「课表管理」里切换当前课表，回到主页就地换成新表，不会再弹回旧的独立课表页。

### 六、导出课表

| 格式 | 内容 |
|---|---|
| **Excel（.xlsx）** | 教务系统同版式：Sheet1 是「星期 × 节次」的课表网格（每格课程名 / 教师 / 周次节次 / 教室），Sheet2 是纯表格的课程明细；Excel / WPS / 手机阅读器都能直接打开 |
| **ICS（.ics）** | 标准日历，可导入系统日历、Google Calendar、WakeUp 等；额外带 `X-LSPX-WEEKS/NODES/DAY/COLOR` 字段，本模块再导入时能无损还原 |

导出落到系统「下载」目录，同名文件自动覆盖，不会产生 `课程表(1).xlsx` 这种副本。

### 六、底栏三段 tab（课程表入口搬到底栏）

- 底栏由「日历 / 待办」变成 **「日历 / 待办 / 课程表」**，点课程表直接进课表页
- 右上角 ⋮ 溢出菜单里原来的「课程表」项隐藏，入口只在底栏
- 底栏右侧按钮从 `+` 换成 **⋮**，点它弹出的就是原来顶部那个「更多」菜单（长按仍是「新建日程」）
